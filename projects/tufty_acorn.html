Tufty Acorn

Background information: The Tufty2040 is a digital badge. If you buy it and connect it to a LiPo battery, you have a low-power-consumption badge for use at events. It is intended for use by relatively technical individuals.

The "Tufty Acorn" system is an attempt to bring accessibility to the system, specifically for plural systems. Rather than making custom python code, it allows users to upload a PluralKit system.json file, which will automatically program the badge with the system's members. Pressing up and down can change the Color Communication Badge displayed, and pressing the letter buttons change the current profile displayed. Created for a friend.
